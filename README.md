# S.H.I.V.A. (Synthetic High-Intelligence Virtual Assistant) ⚡

Personal AI Assistant built specifically for **Shivam Jaiswal** (Boss).

## 🛡️ Strict Security & Access Policy
1. **NO Autonomous Actions**: SHIVA ONLY acts when explicitly commanded by Boss.
2. **Git Push RESTRICTED**: `git push` is permanently banned from automated execution. Boss pushes code to GitHub manually.
3. **2-Step Deletion Guard**: Any file or folder deletion requires two independent confirmations (`CONFIRMATION 1/2` ➔ `CONFIRMATION 2/2`).
4. **Dangerous Commands Blocked**: System formatting or drive-wiping commands are blocked at the kernel/skill level.
